# 2026-11-23 반도체 기술 뉴스 & 논문

## 오늘의 세부 분야: 메모리(Memory) — LPDDR6·SOCAMM2 기반 AI 서버/온디바이스 메모리 경쟁과 PIM(Processing-in-Memory) 표준화

## 뉴스

### 1. [SK하이닉스 뉴스룸] SK하이닉스, 10나노급 6세대 D램 '1c LPDDR6' 개발
- 출처: SK하이닉스 뉴스룸(news.skhynix.co.kr), 2026-03-10
- 링크: https://news.skhynix.co.kr/1c-lpddr6-development-2026/
- 요약: SK하이닉스가 10나노급 6세대(1c) 공정을 적용한 16Gb LPDDR6 D램 개발에 성공했다고 밝혔다. 기존 LPDDR5X 대비 데이터 처리 속도 33% 향상, 전력 효율 20% 이상 개선을 달성했으며 핀당 동작속도는 10.7Gbps 이상이다. 서브채널 구조와 DVFS(동적 전압·주파수 조정) 기술로 전력 효율을 높였고, CES 2026에서 먼저 시제품을 공개한 뒤 개발 인증을 완료했다. 온디바이스 AI를 탑재한 스마트폰·태블릿을 주요 타깃으로 삼아 2026년 하반기 공급을 목표로 한다.

### 2. JEDEC, LPDDR6 로드맵 확대 발표 — 데이터센터용 SOCAMM2·PIM 표준화 추진
- 출처: HPCWire / TrendForce / Businesswire, 2026-04-22
- 링크: https://www.trendforce.com/news/2026/04/24/news-jedec-previews-lpddr6-enhancements-develops-socamm2-standard-for-ai-memory/
- 요약: JEDEC이 모바일 전용이던 LPDDR6를 AI 데이터센터로 확장하는 로드맵을 공개했다. LPDDR6 기반 서버 메모리 모듈 표준 'SOCAMM2'를 개발 중이며, 모듈당 최대 512GB 용량을 지원하는 차세대 사양과 더 좁아진 x6 인터페이스를 검토하고 있다. 또한 메모리와 CPU 간 데이터 이동을 줄이는 'LPDDR6 PIM(Processing-in-Memory)' 표준이 완성 단계에 근접했다고 밝혔다. 2025년 7월 제정된 기본 표준(JESD209-6)에 이은 후속 확장으로, 에이전틱 AI 시대의 메모리 용량·효율 요구에 대응하려는 움직임이다.

### 3. 마이크론, 세계 최초 256GB SOCAMM2 메모리 모듈 양산 샘플 출하
- 출처: wccftech / Tom's Hardware, 2026-10월
- 링크: https://wccftech.com/micron-ships-out-the-worlds-first-256gb-socamm2-modules/
- 요약: 마이크론이 32GB LPDDR5X 칩 64개를 탑재한 256GB SOCAMM2 모듈을 고객사에 샘플 출하했다고 밝혔다. 8채널 서버 CPU에 모듈 8개를 장착하면 총 2TB 용량을 구현할 수 있어, 에이전틱 AI 추론에 필요한 대용량 메모리 수요에 대응한다. 앞서 192GB 모듈을 출하한 데 이어 용량을 확대한 것으로, 삼성전자 역시 엔비디아와 협력해 SOCAMM2를 HBM4와 동시 양산·판매 중이다. SOCAMM2는 기판형 솔더링 방식(LPCAMM 계열) 대비 교체·확장이 쉬워 하이퍼스케일러들의 AI 서버 메모리 용량 확장 전략의 핵심 축으로 부상하고 있다.

## 논문

### 1. Samsung LPDDR5X-PIM: World's First LPDDR based Processing-in-Memory Solution for AI Inference
- 출처: IEEE Hot Chips 38 Symposium (HCS 2026), 2026-08-25 (스탠퍼드 발표)
- 링크: https://www.tomshardware.com/pc-components/dram/hot-chips-2026-samsung-makes-lpddr5x-smart-with-logic-unit-in-memory-lpddr5x-pim-is-3-01x-faster-than-lpddr5x-in-ai-inference-with-8x-the-bandwidth
- 요약: 삼성전자가 LPDDR5X D램 칩 내부에 단순 연산 로직을 내장해 데이터 이동을 줄이는 PIM 솔루션을 Hot Chips 2026에서 공개했다. Llama 3.1 8B 모델 추론에서 기존 LPDDR5X 대비 약 2.3~3배 빠른 처리 속도(5.4초 vs 12.3초)를 보였고, x64 9600Mbps 조건에서 대역폭은 기존 대비 8배인 614GB/s에 달한다. HBM을 대체하기보다 전력·비용에 민감한 온디바이스/모바일 AI 추론용 보완 솔루션으로 포지셔닝했으며, LPDDR6X-PIM의 JEDEC 표준화를 연내 목표로 추진 중이다.

### 2. GUMPIM: Unitary and Malleable Memory for Processing-in-Memory with Guaranteed PIM Pages
- 출처: arXiv (2610.23406), ACM Transactions on Architecture and Code Optimization 게재
- 링크: https://arxiv.org/abs/2610.23406
- 요약: 기존 PIM 시스템은 가상 메모리의 인터리빙 방식 때문에 PIM 유닛이 연속된 데이터에 접근하기 어려워, 메모리를 격리하거나 인터리빙을 꺼야 하는 한계가 있었다. 이 논문은 CPU용 인터리빙 페이지와 PIM용 비인터리빙 페이지가 하나의 메모리 공간에서 공존하도록 하는 이중 트랙 메모리 관리 기법(GUMPIM)을 제안한다. 기존 glibc malloc()은 그대로 두고 PIM 메모리 전용 malloc_pim() API를 도입해 huge page·mlock으로 스왑을 방지한다. CPU 워크로드 성능 저하를 0.1% 미만으로 유지하면서 기존 최신 기법 대비 종단간 2.3배 속도 향상을 달성했다고 보고했다.
