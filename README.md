# Semiconductor Portfolio

반도체 기술을 공부하면서, AI를 활용한 자동화 역량과 문서화 습관을 함께 기르기 위한 개인 포트폴리오 저장소입니다.

## 프로젝트 목적

- **반도체 기술 학습**: 공정, 소자, 회로 등 반도체 관련 이론과 개념을 체계적으로 정리하고 축적합니다.
- **AI 활용 자동화**: 학습 및 작업 과정에서 반복되는 일들을 AI 도구로 자동화하며 실전 활용 능력을 키웁니다.
- **문서화 역량**: 배운 내용과 진행 과정을 꾸준히 기록하여, 성장 과정을 스스로 추적하고 외부에 보여줄 수 있는 포트폴리오로 만듭니다.

## 폴더 구조

### `study-notes/`
반도체 관련 개념, 공정, 이론 등을 학습하며 정리한 노트를 보관합니다. 주제별/공정별로 파일을 나눠 정리하며, 나중에 다시 찾아보기 쉬운 참고 자료를 목표로 합니다.

### `automation/`
학습이나 작업 과정에서 사용한 AI 자동화 스크립트, 프롬프트, 도구 설정 등을 저장합니다. 반복 작업을 효율화한 사례와 그 결과물을 모아둡니다.

### `weekly-logs/`
매주 진행한 학습 내용, 자동화 시도, 느낀 점 등을 기록하는 주간 로그입니다. 시간이 지나며 성장 과정을 돌아볼 수 있는 기록으로 활용합니다.

## 사용 방법

각 폴더 안에 날짜 또는 주제 기반으로 파일을 추가하며 내용을 채워갑니다. 예시:

```
study-notes/
  01-semiconductor-basics.md
  02-cmos-process.md

automation/
  weekly-log-generator.py
  notes-summary-prompt.md

weekly-logs/
  2026-W33.md
  2026-W34.md
```
